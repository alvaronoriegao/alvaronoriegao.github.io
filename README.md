# Alvaro Noriega — Professional Portfolio

A responsive, single-page portfolio website for Alvaro Noriega, focused on operations and business management.

## View the website

Once GitHub Pages finishes publishing, visit: <https://alvaronoriegao.github.io/>

The video section is linked at <https://alvaronoriegao.github.io/#video>.

## Publish with GitHub Pages

This repository is named `alvaronoriegao.github.io`, so GitHub Pages can serve the site at the URL above. In the repository, open **Settings → Pages** and confirm the publishing source is the `main` branch and `/ (root)`. The page may take a few minutes to appear after the first publish.

## Customize

- Edit `index.html` to update the introduction, expertise, contact link, and visual design.
- To add a video, replace the placeholder inside the `#video` section with an accessible responsive YouTube or Vimeo embed.
- Replace the GitHub contact button with a preferred professional contact or social link.
